Задача - нужно создать игровой движок состоящий из подсистем с возможностью добавления новых, пусть каждая подсистема занимаеться своим делом
хотим использовать rust для графического АПИ wgpu
Предпологаемый набор систем

**Основные системы первый уровень** 
    - система для работы с файлами
    - работа с сетью
    - отрисовка
    - анимация
    - работа с ресурсами ( загрузка, выгрузка, кеширование, лимиты)
    - физика 
    - многопоточность
    - система работы с памяти 
    - логирование и тестирование
    - профилирование и сбор статистики
    - парсеры файлов
    - математическая 
    - ECS
    - система ввода
    - чит консоль
    - аудио
    - система событий
**Системы второго уровня**
    Рендеринг: 
    - Камера 
    - Материалы и тени
    - Динамическое и статическое освещение
    - Текст и шрифты
    - Графические элементы отладки
    - Меши
    - Граф сцены 
    - Система определения видимости
    - отрисовки в таргеты
    - система частиц и деколей
    - постэффекты
    Анимация:
    - Скелетная анимация
    - Покадровая анимация
    - Смешивание анимации
    
    

    Основные параметры для систем нужна возможность конфигурирования - при запуске движка
    Мы перечислили самые важные для нас системы - твоя задача проанализировать движки с иходным кодом а также документацию в открытых источниках
    и предложить какие варианты добавить сразу и какие добавить позже - но на первой итерации мы не хотим делать максимально жирный движок - главное чтобы можно
   было удобно расширять - также может даже написать план по итерациях - 1 - минимальный набор для запуски и проверки 2 - остальные важные системы

**Ресурсы**
    - ресурс должен быть расширяемой сущностью чтобы мы могли добавлять новые типы ресурсов и загрузчики для них при этом сохраняя единообразный интерфейс 
    получения ресурсов

**Требовния**
 - Должен работать и собираться на MacOs Linux Андроид и Ios  Web
 - Движок должен поддерживать внеэкранный рендеринг - возможно как отдельный модуль 
 - Хотим глубокую оптимизацию
 - Хотим чтобы код был в одном стиле и желательно человекочитаемый
 - Можно добавлять комментарии, но не делай их огромными
