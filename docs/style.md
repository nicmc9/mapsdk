# Стиль кода

Проверяется автоматически: `cargo fmt --check` и `cargo clippy` с `-D warnings` в CI.
Правила лежат в `rustfmt.toml` и в секции `[workspace.lints]` корневого `Cargo.toml`.

## Именование

| Что | Стиль | Пример |
|-----|-------|--------|
| Типы, трейты, варианты enum | `UpperCamelCase` | `PlatformConfig`, `AssetStatus::Failed` |
| Функции, методы, переменные, модули, крейты | `snake_case` | `init_logging`, `engine_platform` |
| Константы и `static` | `SCREAMING_SNAKE_CASE` | `MAX_DRAW_CALLS` |
| Методы-конвертеры | `as_` (дёшево, ссылка), `to_` (копия), `into_` (забирает владение) | `into_android_app()` |

**[Rust]** Это соглашения самого языка, а не наши: компилятор предупреждает о нарушении.

## Структура

- Один крейт — одна подсистема (`crates/engine_*`). Зависимости идут только вниз по слоям (`acrhitecture.md`).
- Наружу из крейта видно только то, что реэкспортировано в `lib.rs`. Внутренние модули — без `pub`.
- Типы сторонних библиотек не выходят за пределы своего крейта: снаружи — свои типы или псевдонимы.
- Платформенный код — через `#[cfg(...)]` на уровне функций или модулей, а не внутри длинных функций.

## Ошибки

- Ожидаемые ошибки — `Result<T, E>` и `?`. Тип ошибки подсистемы — enum с `thiserror`.
- `panic!`, `unwrap()`, `expect()` — только для нарушения инвариантов (бага в коде).
  В тестах и примерах `unwrap()` допустим.
- Игнорирование результата — только явно: `let _ = ...;` с комментарием, почему ошибку можно не обрабатывать.

## unsafe

- Запрещён по умолчанию (`unsafe_code = "deny"`).
- Разрешается точечно через `#[allow(unsafe_code)]`, рядом — комментарий: зачем и почему это безопасно.

## Комментарии

- `///` — документация публичного API (что делает, особенности платформ). `//` — пояснение реализации.
- Коротко: 1–3 строки. Пишем *почему*, а не пересказываем код.
- Неочевидные для C++ места помечаем `[Rust]`.
- Язык комментариев — русский, идентификаторы — английский.

## Зависимости

- Версии — только в `[workspace.dependencies]` корневого `Cargo.toml`, в крейтах — `{ workspace = true }`.
- Каждый новый крейт сразу описывается в `docs/crates.md`.
