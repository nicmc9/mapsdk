# Лицензии тестовых ресурсов

Ресурсы в `assets/` — для проверки движка, не для продукта. Перед добавлением нового ресурса
запишите его сюда. Ресурсы с ограниченной или неизвестной лицензией в git не кладём
(репозиторий публичный): они скачиваются скриптом или лежат только локально.

## Khronos glTF-Sample-Assets

Источник: https://github.com/KhronosGroup/glTF-Sample-Assets, коммит `8f492390`.
Скачать или обновить: `./assets/fetch_khronos.sh`. Полный текст лицензии и авторы — в
`LICENSE.md` и `README.md` в папке каждой модели.

| Модель | Лицензия | В git | Для чего |
|--------|----------|-------|----------|
| Box | CC BY 4.0 | да | Первые тесты загрузчика |
| BoxTextured | CC BY 4.0, товарный знак Cesium | да | Текстуры, сравнение картинок |
| DamagedHelmet | CC BY 4.0 + **CC BY-NC 4.0** | да | Эталон PBR. Только некоммерческое использование — в продукт не включать |
| CesiumMan | CC BY 4.0, товарный знак Cesium | да | Скелетная анимация |
| Fox | CC0 1.0 + CC BY 4.0 | да | Скелетная анимация, несколько клипов |
| Sponza | Cryengine Limited License | **нет** | Большая сцена: отсечение, свет, тени. Только через скрипт |
